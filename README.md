# ระบบเช็คชื่อเข้าเรียนด้วยการแสกนหน้า

เว็บ + หลังบ้าน + QR Code ต่อห้อง + รองรับ ESP32 (Node.js ล้วน ไม่ต้องติดตั้งแพ็กเกจ)

## เริ่มใช้งาน
```bash
cd face-attendance
ADMIN_PASSWORD=รหัสของคุณ DEVICE_KEY=คีย์ลับของESP32 node server.js
```
เปิด http://localhost:3000/admin.html (รหัสเริ่มต้น `admin1234` — ควรเปลี่ยน)

## ขั้นตอน
1. **ห้องเรียน & QR Code** → สร้างห้อง → ได้ QR ของแต่ละห้อง (ดาวน์โหลด/พิมพ์ติดหน้าห้อง)
2. **นักเรียน** → กรอกรหัส ชื่อ สาขา → เปิดกล้อง → จับภาพใบหน้า → บันทึก
3. นักเรียนใช้มือถือแสกน QR ของห้อง → เปิดหน้าแสกนหน้า → ขึ้น **"แสกนสำเร็จ"**
4. **บันทึกเข้าเรียน** ในหลังบ้านจะแสดง วันที่/เวลา, ชื่อ, **สาขา**, ห้อง (กรองตามวัน/สาขา/ห้อง, ส่งออก CSV)

## ข้อควรระวัง: ต้องใช้ HTTPS
เบราว์เซอร์อนุญาตให้ใช้กล้องเฉพาะ `https://` หรือ `localhost` เท่านั้น
ถ้าเปิดจากมือถือผ่าน `http://192.168.x.x:3000` กล้องจะไม่ทำงาน ให้ใช้อย่างใดอย่างหนึ่ง
- ใช้ tunnel ฟรี เช่น `cloudflared tunnel --url http://localhost:3000` หรือ ngrok แล้วนำ URL https ไปใส่ช่อง "ที่อยู่เว็บ" ในแท็บ QR
- นำขึ้นโฮสต์ที่มี HTTPS (Render, Railway, VPS + Caddy ฯลฯ)

## ESP32
ส่งเช็คชื่อด้วย HTTP POST:
```
POST /api/device/attendance
x-device-key: <DEVICE_KEY>
{"studentId":"001","roomId":"<รหัสห้อง>"}
```
ตัวอย่างโค้ด: `esp32/esp32_attendance.ino` (แก้ WiFi, IP เซิร์ฟเวอร์, DEVICE_KEY, ROOM_ID)
นอกจาก `studentId` ยังส่ง `descriptor` (เวกเตอร์ใบหน้า 128 ค่า) ให้เซิร์ฟเวอร์จับคู่เองได้

## ตั้งค่า (ตัวแปรสภาพแวดล้อม)
| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| PORT | 3000 | พอร์ต |
| ADMIN_PASSWORD | admin1234 | รหัสหลังบ้าน |
| DEVICE_KEY | esp32-secret | คีย์ของอุปกรณ์ ESP32 |
| MATCH_THRESHOLD | 0.5 | ความเข้มงวดการจับคู่ใบหน้า (น้อย = เข้มงวด) |
| DUP_MINUTES | 5 | กันบันทึกซ้ำของคนเดิมในห้องเดิม (นาที) |

ข้อมูลเก็บที่ `data/db.json` (สำรองไฟล์นี้ไว้)

## ข้อจำกัด
การแสกนหน้านี้ไม่มีระบบกันรูปถ่าย (liveness) หากต้องการความปลอดภัยสูงควรเพิ่มการตรวจจับการกะพริบตา
